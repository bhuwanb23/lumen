# Lumen assets

A compact visual asset set for the Lumen source-linked pathology-report conversation prototype. The set contains **8 visual concepts** in editable SVG and PNG exports (16 image files): three brand assets and five project infographics.

## Brand
- `lumen-wordmark.svg` / `.png` — horizontal logo lockup for covers and headers.
- `lumen-mark.svg` / `.png` — standalone source-link symbol.
- `lumen-app-icon.svg` / `.png` — square app tile.

## Project visuals
- `experience_map.svg` / `.png` — patient-facing interaction path and stop states.
- `data_boundary.svg` / `.png` — high-level information flow and provider boundary.
- `evidence_gate.svg` / `.png` — source/evidence check, supported path, and abstention.
- `dataset_profile.svg` / `.png` — synthetic fixture counts and gold-span integrity.
- `redteam_profile.svg` / `.png` — red-team fixture inventory by category.

PNG exports are generated from the accompanying SVGs. Counts describe synthetic fixtures or software checks only; the graphics are not model-performance or clinical evidence. The product is a synthetic-only prototype, its provider is disabled, and it is not for clinical decisions or patient use.
